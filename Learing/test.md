# 🚀 DeepAgents Installation Guide

Welcome to the documentation. Please expand the appropriate section below depending on your preferred Python package manager.

---

### 📦 Installation Options

<details>
<summary>📋 <b>Option A: Install via pip</b></summary>
<br>

Use standard `pip` to pull the latest version directly from PyPI:

```bash
pip install deepagents
```

</details>

<details>
<summary>⚡ <b>Option B: Install via uv (Fast)</b></summary>
<br>

If you are using the extremely fast `uv` ecosystem, run the following command:

```bash
uv pip install deepagents
```

</details>

---

### 🔍 Quick Verification
After choosing your install method, you can verify it works by opening a Python terminal and running:
```python
import deepagents
print(deepagents.__version__)
```
